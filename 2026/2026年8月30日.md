# Python 字典 dict

dictionary字典是一个通用的数据结构，广泛运用在很多领域。字典里的一个元素是由一个键（key）和一个值（value）构成的键值对，很多键值对的集合构成了一个字典。

比如说“Kitty={e | 性别：女，年龄：18岁}”就可以构成一个字典。其中，“性别”和“年龄“是key，”女“和”18岁“是value。我们在使用时通过 key能够 快速查找 value。这种结构和我们查的字典、电话本相同，所以大多数现实世界的对象度可以表达为字典，或者是更加复杂的字典的嵌套格式。

在python中用函数dict()来定义字典，也可以用简化的方式表达，即使用中括号{}实：

1. **存储形式**：`{键:值, 键:值}`，key（键）和 value（值）一一对应

   ```
   d = dict({"name":"张三", "age":18})
   d = dict(name="张三", age= 18)
   d = {"name":"张三", "age":18}
   ```

2. **特点**

> 键键键`key`必须不可变：字符串、数字、元组；**列表不能做 key**
> 值`value`任意类型：列表、字典、数字、图像等等都可以
> key 唯一，重复写后面的会覆盖前面

1. **取值**：`d["name"]`，key 不存在的话会直接报错；`d.get("name")`找不到返回 None，更安全
2. **常用方法**

- `d.keys()` 获取所有键
- `d.values()` 获取所有值
- `d.items()` 获取键值对
- `d["age"]=20` 修改 / 新增元素
- `del d["age"]` 删除元素



另外，在python中存储字典其实就是将其通过翻译程序转化为哈希值，可以理解为数据相对来说唯一的的编码，它具备相同数据结果一致、改动数据值就剧变、单向不可还原的特点，常用来校验文件、实现快速查找与安全保存密码。

下面是一个例子：

```
import hashlib

s = "hello"
res = hashlib.md5(s.encode()).hexdigest()
print(res)
#输出：5d41402abc4b2a76b9719d911017c592
```

通过这串简单的代码，我可以快速查找单词错误次数。

```
err_dict = {"money": 2, "good":0, "ethusastic": 10, "fynancy":8 }
word = "ethusastic"
print(f"单词{word}错了{err_dict[word]}次")

sorted_keys = sorted(err_dict, key=err_dict.get)
print(sorted_keys) 
```
