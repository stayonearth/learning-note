## 常见问题

### 1. 为什么要学习 Python？

Python 不可否认的确是这个时代最流行、也必须要掌握的编程语言。

### 2. 怎么用 Python？

这是我目前正在学习的内容。作者建议从 **工程的角度** 来学习 Python：

1. **不同的语言需融会贯通** — 要能够明确区分并灵活运用
2. **把握学习重点** — Python 作为主流语言，要明确学习重点，把握好学习节奏，稳步进阶
3. **先打基础，再实践突破** — 优先打下良好的基础和规范，之后通过实践积攒经验，实现质的突破
