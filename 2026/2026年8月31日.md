title:标点符号的运用

在编程语言中，字符串是重要的组成部分，在日常生活中，我们无时无刻都在使用字符串，所以学习字符串是学习编程甚至计算机的基础。

字符串是由独立字符组成的一个序列，其中引号发挥着重要作用，Python 同时支持单引号、双引号、三引号这三种表达方式，很重要的一个原因就是，这样方便你在字符串中，内嵌带引号的字符串。比如：

```
s1 = 'hello'
s2 = "hello"
s3 = """hello"""
s1 == s2 == s3
True
```

python也同样支持转义字符，以它们开头的字符串可以表示某些特定意义，可以帮助我们进行排版。

```
s = 'a\nb\tc'
print(s)
a
b  c
```

但我们要注意，Python 中字符串是不可变的（新版本 Python 中拼接操作’+='是个例外）。因此，随意改变字符串中字符的值，是不被允许的。

字符串便利我们的编程，使其更加格式化，能够让人和机器都能够清晰的理解。因此，熟练运用字符串是学习编程的过程中必不可少的一步。
